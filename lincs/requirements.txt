# LINCS L1000 / DM-ADIGen — Python dependencies.
#
# Start from the RxRx19a pins (working cluster env: `conda activate
# torch-cuda`, Python 3.8.20, CUDA 12.1, A6000 / sm_86) plus the GCTX/HDF5
# stack. Pinned rather than floated so the HF `datasets` Arrow schema and
# `accelerate` checkpoint layout stay compatible with artifacts already on
# disk. Python 3.8 caps most of them anyway.
#
#   conda create -n torch-cuda python=3.8 && conda activate torch-cuda
#   pip install -r requirements.txt
#
# torch/torchvision are NOT in the list below: install them first, from the
# wheel index that matches the cluster's CUDA, then run the pip install above.
#
#   pip install torch==2.4.1 torchvision==0.19.1 \
#       --index-url https://download.pytorch.org/whl/cu121
#
# (The live env reports torchvision 0.20.0 against torch 2.4.1 -- it imports, but
# 0.20.0's metadata wants torch 2.5.0, so a fresh install won't resolve it.
# 0.19.1 is the matched pair.)
#
# NB the env's PyTorch supports up to sm_90, so every GPU job pins
# `--gres=gpu:nvidia_rtx_a6000` — it cannot run on the Blackwell (sm_120) cards.
#
# Ingest (`src.data.build_dataset`) needs pandas / numpy / h5py / datasets.
# cmapPy and tables are listed because the LINCS spec asks for them; the GCTX
# reader itself is h5py on the uncompressed file. timm is not required for
# ingest (later 1D-DiT may use Attention/Mlp only). Do not install OpenPhenom
# or third_party/maes_microscopy.
